# 复古宝宝写真提示词大师

面向中国宝宝儿童摄影与影楼写真场景的 Prompt Skill。它把宝宝参考图、月龄、服装、姿态、道具、背景、色彩、画幅和张数，编译成可直接使用的完整中文生图提示词。

支持宝宝身份锁定、同系列多张独立写真、百天照、趣味主题布景、写实影棚摄影、生活方式儿童写真、主题母版复用，以及中国儿童影楼常用的色彩、道具叙事和构图控制。

## 安装

### 全局安装

```bash
npx skills add ktingshu/baby-portrait-prompt-skill -g -y
```

### 更新已有安装

```bash
npx skills update generate-baby-portrait-prompts -g -y
```

更新后，新建任务或重新加载 Agent，让新版指令进入上下文。

## 它解决什么

普通请求默认只输出完整提示词，不会擅自生成图片。

当用户提供宝宝参考图时，技能会把参考图明确分为人物身份、服装、姿态、道具、构图和风格等角色，避免把道具图误当成宝宝身份图。

当用户要求多张写真时，技能会锁定同一宝宝的脸型、五官比例、肤色、发型、肉感和辨识度，为每张输出独立提示词，不生成拼图、九宫格或接触表。

当用户给出不完整变量时，技能会根据月龄、动作能力、摄影逻辑和中国儿童影楼审美自动补齐，而不是随机堆叠服装和道具。

## 普通调用

```text
使用 $generate-baby-portrait-prompts，为这个宝宝主题写一组写真提示词。
```

也可以直接发送变量：

```text
宝宝参考图：
月龄与性别：5个月，中国男宝宝
主题：夏日泳池
服装：
姿态：
道具：
背景：
色彩：
画幅：4:5
张数：5张
输出：只要提示词
```

缺失项不影响执行，技能会使用适合宝宝月龄的默认参数补齐。

## 输出规则

### 默认输出

默认只输出一段或多段可直接生图的完整正向提示词，不加无关解释。

### 多张任务

每张必须是独立照片，并锁定同一宝宝身份：

```text
单张独立照片，不是拼图、组图、分镜或多宫格。
```

### 完整提示词与画面解构

用户明确要求时，先输出完整提示词，再输出“画面解构”，包括主体身份、姿态、服装、道具、场景、构图、机位、镜头、光线、色彩和主体占比。

## 核心控制逻辑

技能默认遵循以下优先级：

```text
身份一致性
> 月龄与动作合理性
> 肢体和道具接触关系
> 服装结构与材质
> 主题叙事
> 构图、光线与影像质感
```

中国儿童影楼布景通常采用“一个主视觉符号 + 两到四个重复陪衬 + 一层背景结构”的方法。道具按前景、中景、背景分层，避免平均铺满画面；宝宝脸部和眼睛始终是第一视觉焦点。

## 安全与生成边界

1. 低月龄宝宝优先使用仰卧、趴卧抬头、软垫半躺或隐藏承托姿态，不为了模仿构图强行站立或无支撑坐姿。
2. 纸袋孔洞脸部主题会转换为固定在背景架上的平面印刷布景，不让纸袋套住宝宝头部或贴住口鼻。
3. 洗衣机主题会转换为断电、开放式、无机械结构的摄影外壳，宝宝只在滚筒口外被安全承托。
4. 头饰、耳机、围巾、气球线和小道具不得压迫、缠绕或遮挡宝宝口鼻。
5. 默认去除随机文字、Logo、水印和摄影机构标识；只有用户逐字指定时才保留指定文字或品牌元素。
6. 使用参考图和人物图前，请自行确认版权、肖像权、商标和平台规则。

## 能力边界

本项目重建的是可观察的儿童摄影方案：宝宝身份一致性、姿态、光线、机位、布景、道具关系和成像质感，不承诺像素级复刻。

技能只在用户明确要求时生成图片；只要提示词时不会擅自调用图像生成工具。生成结果仍会受到参考图质量、模型能力、人物授权和平台规则影响。
