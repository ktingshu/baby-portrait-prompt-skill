# 宝宝写真 Prompt Schema

## 输入变量

| 参数 | 允许内容 | 处理规则 |
| --- | --- | --- |
| identity_reference | 宝宝照片编号 | 指定唯一身份母版，不从其他图混脸 |
| age | 月龄、百天、周岁 | 决定可行姿态和身体比例 |
| sex | 男宝宝、女宝宝、未指定 | 未指定时不强化性别符号 |
| series | 主题名 | 映射主题符号、色板和道具 |
| expression | 好奇、浅笑、发呆等 | 保留原生神态，避免成人式表演 |
| headwear | 头巾、帽子、头盔等 | 写明颜色、材料、结构和佩戴方式 |
| wardrobe | 上衣、包屁衣、背带裤、袜子 | 写清内外层、领型、滚边、图案、面料 |
| pose | 仰卧、趴卧、坐姿等 | 与月龄匹配，说明朝向和支撑面 |
| hand_action | 抓、牵、扶、自然放置 | 明确左右手、接触点、受力和遮挡 |
| hero_prop | 番茄、气球、耳机等 | 锁定数量、位置、尺度、材质、持有者 |
| support_props | 玩具、收音机、玩偶等 | 控制数量，不抢主体 |
| background | 纯色、居家、影棚 | 定义颜色、距离、纹理和干净度 |
| palette | 主色、辅色、点缀色 | 通常不超过三个核心色族 |
| composition | 特写、半身、全身 | 定义人物占比、留白和裁切边界 |
| camera | 机位、焦段、景深 | 保持真实人像透视，避免畸变超广角 |
| lighting | 自然光、柔光棚拍 | 定义方向、软硬、光比和眼神光 |
| rendering | 写实数码、复古胶片 | 只改变影像层，不破坏皮肤结构 |
| aspect_ratio | 1:1、3:4、4:5、9:16 | 未指定使用 4:5 竖版 |
| count | 1–N | 多张独立输出，身份与造型母版一致 |
| text_rule | 无文字或精确文案 | 默认无文字；指定文案逐字锁定且只出现一次 |
| output_mode | 仅提示词、提示词＋解构、直接生图 | 默认仅提示词 |

## 默认参数

- 写实影楼或室内生活方式宝宝写真，4:5 竖版。
- 近景主体占比 65%–80%；全身坐姿 55%–70%。
- 50–85mm 等效焦段，宝宝眼睛高度附近的平视或轻微高机位。
- 45° 侧前方大型柔光，低光比补光，主体与背景分离半档至一档。
- 白嫩但保留真实肤色层次、细小绒毛、自然脸颊肉感和轻淡腮红。
- 场景简洁，道具稀疏，接触阴影完整。

## 冲突规则

1. 用户明确指令高于默认值。
2. 身份保持高于“更可爱、更白”；只微调肤色和妆感，不改骨相五官。
3. 月龄安全高于指定动作；动作不合理时替换为视觉意图最接近的安全姿态。
4. 产品或道具参考结构高于风格化改造。
5. 真实摄影高于夸张装饰；使用能讲清主题的最少元素。
6. 指定文字与清除文字冲突时，以最后一次明确要求为准。
7. 多张独立输出高于系列海报布局；禁止 N 宫格。

## 静默质检

- 身份唯一，无换脸、成人化或动漫化。
- 姿态匹配月龄，头颈和躯干有合理支撑。
- 可见手脚数量正确，手指完整，无融合穿模。
- 帽子、耳机、气球线、食物、玩偶符合重力并真实接触。
- 服装内外层、颜色、滚边、图案和袜子互不冲突。
- 背景干净，陪衬不抢主体，小物不贴近口鼻。
- 机位、焦段、光线、景深和材质表现一致。
- 只保留指定文字，无随机文字、Logo、水印。
- 多张任务输出独立单图，不做拼图。

## 输出骨架

`[任务/画幅/单张规则]，[身份锁定]；[月龄、性别、比例、面部与表情]；[头饰]，[服装结构与材质]；[姿态、朝向、可见肢体]，[手部和主道具接触]；[背景、支撑面、陪衬、空间层次]；[色彩系统]；[构图、主体占比、机位、焦段、景深]；[主光、补光、眼神光、接触阴影]；[皮肤与其他材质]；[摄影媒介、分辨率、调色]；[文字与统一约束]。`
